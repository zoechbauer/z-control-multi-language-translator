Note

Translate from the base language into up to {{ maxTargetLanguages }} target languages simultaneously.

How to select target languages:

  1. Click Select target language(s).
  2. The list with all available target languages opens.
  3. Select 1 to 5 target languages by clicking the checkbox on the right.
  4. Click the checkbox again to remove a language from the selection.
  5. You can scroll through the list or use the search function.
  6. Type in the search field to quickly find matching languages.
  7. Click on the left side of the search bar to show only selected target languages.
  8. Click , to reset both filters (search text and selection) and show all languages again.
  9. The number and language codes of selected target languages are always shown at the top.
  10. When you are done, close the selection with X.
  11. You will then return to this page.
  12. Click Back to Settings to stay in the settings area.
  13. Or click in the header to go directly to the translation page.

Note about the base language

The base language cannot be selected as a target language and is therefore not included in the list.

To change the base language, go to Settings > Language / Base language.

You can change the base language and target languages at any time.

Please select your desired target languages.

Hinweis

Sie können Text von der Basissprache in bis zu {{ maxTargetLanguages }} Zielsprachen gleichzeitig übersetzen.

So wählen Sie Zielsprachen aus:

  1. Klicken Sie auf Zielsprache(n) auswählen.
  2. Es öffnet sich die Liste mit allen verfügbaren Zielsprachen.
  3. Wählen Sie 1 bis 5 Zielsprachen aus, indem Sie rechts auf das Auswahlfeld klicken.
  4. Ein erneuter Klick auf das Auswahlfeld entfernt die Sprache wieder.
  5. Sie können in der Liste scrollen oder die Suchfunktion verwenden.
  6. Geben Sie im Suchfeld einen Text ein, um passende Sprachen schneller zu finden.
  7. Klicken Sie links in der Suchleiste auf , um nur ausgewählte Zielsprachen anzuzeigen.
  8. Klicken Sie auf , um beide Filter (Suchtext und Auswahl) zurückzusetzen und alle Sprachen anzuzeigen.
  9. Oben sehen Sie jederzeit die Anzahl und Kürzel der ausgewählten Zielsprachen.
  10. Wenn Sie fertig sind, schließen Sie die Auswahl mit X.
  11. Sie gelangen danach zurück auf diese Seite.
  12. Klicken Sie auf Zurück zu Einstellungen, um in den Einstellungen zu bleiben.
  13. Oder klicken Sie im Kopfbereich auf , um direkt zur Übersetzungsseite zu wechseln.

Hinweis zur Basissprache

Die Basissprache kann nicht als Zielsprache ausgewählt werden und ist deshalb nicht in der Liste enthalten.

Um die Basissprache zu ändern, gehen Sie zu Einstellungen > Sprache / Basissprache.

Sie können die Basissprache und die Zielsprachen jederzeit ändern.

Bitte wählen Sie die gewünschten Zielsprachen aus.
